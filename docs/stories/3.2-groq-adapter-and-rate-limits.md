# Story 3.2 — Groq adapter and rate-limit handling

As the developer, I want a working provider adapter behind the agent port, so that a real model can play a match at zero cost.

**Requires a human-supplied `GROQ_API_KEY` in the environment. Escalate if absent — do not stub past it and mark the story done.**

## Acceptance criteria

**Given** a configured Groq Deployment, **When** it plays a Match, **Then** a valid Command Log is produced with `provider: "groq"` and the real endpoint recorded on every entry.

**Given** a rate-limit response, **When** it is received, **Then** the adapter surfaces it as a typed signal and backs off — it does not fail the Match and does not retry the decision.

**Given** the adapter, **When** inspected, **Then** it holds no cross-call state. Quota bookkeeping is the runner's job.

**Given** a provider response, **When** usage is extracted, **Then** the adapter reports raw counts only and performs no bank arithmetic.

**Given** free-tier limits, **When** they are referenced, **Then** they come from a config file, not from constants in code.

## Scope

`packages/providers`: the provider interface plus the Groq adapter. Baseline as measured 2026-07-30 — 30 RPM / 14,400 RPD on `llama-3.1-8b-instant`, 1,000 RPD for most other models. **Re-verify before relying on these; they move.**

## Frozen contracts touched

None modified.

## Invariants at risk

- **INV-4** — no effort parameter in the request body.
- **INV-6** — provider and endpoint recorded per call, not per Match.
- **INV-8** — free tier only; a paid endpoint must fail config validation.

## Architecture decisions that constrain this

- **AD-6** — adapters report raw usage; the Harness owns the debit.
- **AD-9** — adapters are stateless per call; backoff and quota state live in the runner.

## Test plan

Recorded-fixture tests for response parsing so the suite runs without network. One opt-in live smoke test behind an env flag. Rate-limit signal typing. A test asserting no bank arithmetic exists in the adapter.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Never widen a frozen interface.
