# Story 4.7 — Bring your own model, not just your own key

As a visitor with an API key, I want to fight with any model my key can reach — including one that shipped last week — so that the picker is not a museum of whatever was current when this page was written.

## Why this exists

Story 4.6 offers four models across three providers, hard-listed from
`free-tier.config.json`. Models come and go weekly. A curated list is stale the
day it lands, and OpenRouter alone carries hundreds — no list maintained by this
repo can track that.

Three things follow, and the third is the one that matters:

1. The curated list is out of date already. Groq's free production tier is
   `llama-3.1-8b-instant`, `llama-3.3-70b-versatile`, `openai/gpt-oss-120b` and
   `openai/gpt-oss-20b` — we offer the first only. Note the third and fourth:
   OpenAI's open-weight models, free, no OpenAI account.
2. A visitor may hold a **paid** key. Nothing about BYOK requires their model to
   be free — see the invariant note below.
3. Every provider already publishes its own catalogue, behind the visitor's own
   key. Asking *them* is the only version of this that never goes stale.

## Acceptance criteria

**Given** a provider whose model travels in the request body, **When** the visitor types a model name that is not on any list, **Then** the Match runs against it and the Command Log records that model verbatim.

**Given** a pasted key, **When** the visitor asks for their models, **Then** the picker is populated from that provider's own model endpoint, called with that visitor's key and sent to that provider's origin and no other.

**Given** no key pasted yet, **When** the picker is shown, **Then** a curated fallback list is offered, and the custom-name box is available without a key.

**Given** a model name that the provider rejects as unknown or retired, **When** the Match is attempted, **Then** the visitor is told *that specific thing* — not a generic provider error — and no partially-recorded Match is produced.

**Given** Google AI Studio, **Whose** model is part of the URL path, **Then** its models stay a fixed allowlisted list, and the reason is stated in the picker rather than left as an inconsistency.

**Given** OpenRouter, **When** it is offered, **Then** it is reachable with a custom model name, and it is no longer labelled CLI-only.

## Scope

`packages/providers`: an OpenRouter adapter (OpenAI-compatible, so it is mostly
configuration) and a model-discovery call per provider. `apps/web`: the custom
model field, the "fetch my models" path, and the fallback list.

Verify OpenRouter's CORS preflight the way 4.6 did, and record it in
`docs/reports/byok-cors-preflight.md` beside the others.

## Invariants at risk

- **INV-8** — read carefully before touching anything. The machine check is on
  **endpoints**, not models: `assertFreeTierEndpoint` validates the URL a key is
  sent to, and for every provider except Google the model travels in the request
  body. So a custom model name does not touch the check at all.

  What this story **does** record, as an interpretation rather than a change:
  *the free-tier allowlist governs tournament play, which runs on this
  project's keys and is where a recurring cost could appear. A BYOK Match runs
  on the visitor's key and costs this project nothing, whatever model they
  choose.* Every endpoint added here must still have a free tier — OpenRouter's
  does (`:free` models) — so the allowlist stays exactly as strict as it was.
  Tournament configuration must remain free-tier-only, and
  `tournament-config.ts`'s existing refusal of OpenRouter must survive this
  story unchanged.

  If any of that reading seems wrong, **stop and escalate** rather than
  loosening `assertFreeTierEndpoint`.
- **INV-6** — a custom model name is recorded per call like any other.
- **AC1 of 4.6** — the model-discovery call is a *new request*, and it must go to
  the same origin as the fight. The origin test must cover it.

## Architecture decisions that constrain this

- **AD-11** — still BYOK, still excluded from every rating. A paid model does not
  buy a leaderboard row.
- **AD-4** — no server. Model discovery is browser-to-provider, same as the fight.

## Test plan

Custom model reaches the wire and the log verbatim. Discovery populates from a
recorded response and contacts one origin. Unknown-model failure is attributed
and distinct from a generic provider error. Google keeps its fixed list and says
why. OpenRouter is selectable and its CORS verdict is recorded. Tournament
config still refuses OpenRouter.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`,
**stop and escalate**.
