# Story 2.4 — The skill separation gate

As the developer, I want proof that a stronger player reliably beats a weaker one, so that the leaderboard measures something instead of producing noise.

**This is the project's highest-risk assumption and the gate on every remaining epic.**

## Acceptance criteria

**Given** the three Baseline Bots, **When** each pairing plays **at least 200 Matches** (100 seeds × 2 side swaps), **Then** win rates are strictly ordered with non-overlapping 95% confidence intervals.

**Given** those results, **When** CI lower bounds are computed, **Then** all three thresholds hold: spacing-aware over random **≥ 0.65**; spacing-aware over aggressive **≥ 0.55**; aggressive over random **≥ 0.50**.

**Given** the gate run, **When** it completes, **Then** a committed report records win rates, CIs, match counts and the frame-data config hash used.

**Given** a failing gate, **When** the run finishes, **Then** the story **stops and escalates**. Deepening the game is the fix. Lowering the thresholds is not — they were committed up front precisely so they could not be moved to fit results.

## Scope

A gate runner that plays the bot ladder, computes bootstrapped CIs, and emits a report. No LLMs involved — this must pass before any token is spent.

Expect to iterate on 2.2's frame data. If the spacing-aware bot does not clearly beat the aggressive bot, the Commitment Window numbers are wrong, not the bots.

## Frozen contracts touched

None modified. Gate matches produce ordinary Command Logs.

## Invariants at risk

- **INV-2** — 200 matches per pairing will surface any non-determinism E1 missed. Treat a hash mismatch here as a determinism bug, not flakiness.

## Architecture decisions that constrain this

- **AD-12** — every seed is played from both sides; side swaps are separate Matches with distinct `matchId`s.
- **AD-5** — bootstrap resampling must itself be seeded, or the gate result will not reproduce.

## Test plan

The gate run is the test. Additionally: a unit test of the bootstrap CI implementation against a known distribution, and a test that the gate correctly *fails* when fed synthetic 50/50 results.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero **AND** the three CI thresholds met.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Never widen a frozen interface. Equally: never widen the gate thresholds.
