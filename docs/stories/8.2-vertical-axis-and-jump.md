# Story 8.2 — Vertical axis and jump

As the fight, I want a `jump` Action with a real vertical axis, so that positioning stops being a single line and starts being a plane.

## Acceptance criteria

**Given** `FighterState`, **When** `jump` is added, **Then** state gains a vertical position and air-state per Agent, both integers — no float anywhere (INV-2).

**Given** `jump` is committed, **When** its Commitment Window runs, **Then** it occupies rise → apex → fall exactly the way `attack`/`special` occupy startup → active → recovery, ticked by the existing `windowFor`/`phaseOf` machinery in `frames.ts` — no parallel window system.

**Given** a fighter mid-jump, **When** a Decision Point is polled for it, **Then** it is not polled at all — inside a Commitment Window, same as any other committed Action. Air-attacks and juggle interactions are Story 8.4's concern, not this one; this story ships jump as a clean rise-and-land.

**Given** gravity, **When** a Tick advances during the jump window, **Then** vertical position updates by a fixed-point integer step per Tick. No delta-time, no float.

**Given** jump height and rise/fall Tick counts, **When** they're read, **Then** they come from `FighterConfig`, never a constant in code — the same discipline `frames.ts` already applies to Commitment Windows.

**Given** the arena, **When** any Tick resolves, **Then** vertical position never goes below the floor.

## Scope

`packages/env-fighter/src/state.ts` (vertical position + air-state fields), `frames.ts` (jump window shape), `config.ts` (jump config values), `environment.ts` (gravity integration in `step()`). No `docs/contracts/` change — 8.1 already landed the schema and grammar.

## Frozen contracts touched

None. If this story finds itself needing a schema or grammar field 8.1 didn't add, that's a signal to go fix 8.1, not to widen the contract from here.

## Invariants at risk

- **INV-1** — jump timing is Tick-counted only; no `Date.now`/`performance.now` anywhere near it.
- **INV-2** — gravity is fixed-point integer arithmetic; the determinism gate (100 replays, in-process and cross-process) must hold with jump sequences included.

## Architecture decisions that constrain this

- **AD-5** — determinism is structural: integers only, fixed timestep, no delta-time.
- **AD-13** — this story is the first real consumer of the vertical-position field 8.1 added to the schema.

## Test plan

Unit tests for jump-window phase transitions against config values. Determinism fixture containing jump sequences replays to an identical Final-State Hash, both in-process and cross-process (extends the existing replay-determinism gate). Property test: vertical position is never negative across a randomized (seeded) sequence of jumps.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate** — schema and grammar changes belong to Story 8.1 alone.
