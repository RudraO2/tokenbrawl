# Story 4.5 — Timeline scrub with side-by-side reasoning

As a visitor, I want to jump to any moment and read both fighters' thinking at once, so that I can compare how two models read the same position.

## Acceptance criteria

**Given** the timeline, **When** a visitor seeks to a Decision Point, **Then** the rendered state is exactly what the Command Log records for it.

**Given** any seek position, **When** the panel renders, **Then** both Agents' reasoning for that Decision Point appears side by side.

**Given** seeking backwards, **When** it happens, **Then** state is correct — re-simulate from the start rather than attempting to reverse the simulation.

**Given** playback speed, **When** anything is scrubbed, **Then** it remains constant and independent of the original Match wall-clock durations.

## Scope

`apps/web`: timeline control, seek, and the dual reasoning panel. Seeking re-simulates from tick zero to the target; the state is small enough that this is cheap and it keeps AD-4 intact.

## Frozen contracts touched

None modified.

## Invariants at risk

- **INV-2** — a seek that produces different state than continuous playback is a determinism bug.
- **INV-3** — constant playback speed.

## Architecture decisions that constrain this

- **AD-4** — re-simulate to seek; never store frames to make scrubbing easier.

## Test plan

Seek-versus-play-through state equality at sampled points. Backwards seek. Dual reasoning correspondence. Constant pacing after scrubbing.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.
