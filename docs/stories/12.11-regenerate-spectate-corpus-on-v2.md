# Story 12.11 — The stream stops being a v1 corpus that never shows anything

As a viewer, I want the fights that loop on screen to contain the things this project built, so that the Ultimate, the cinematic and the whole of Epic 8 are not features that exist only in the test suite.

## The gap, measured

Every Command Log committed under `apps/web/public/replays/`, read on 2026-08-10:

| Log | schema | ending | `special` | `jump` |
|---|---|---|---|---|
| `demo` | 1.0.0 | timeout | 0 | 0 |
| `spectate-01` | 1.0.0 | **ko** | 0 | 0 |
| `spectate-02` | 1.0.0 | timeout | 0 | 0 |
| `spectate-03` | 1.0.0 | timeout | **1** | 0 |
| `spectate-04` | 1.0.0 | timeout | 0 | 0 |
| `spectate-05` | 1.0.0 | timeout | 0 | 0 |
| `spectate-06` | 1.0.0 | timeout | 0 | 0 |
| **totals** | | 6 timeouts, 1 KO | **1 in 379 submissions** | **0** |

Three findings, and they are not the same kind of problem.

**One — the Ultimate is effectively unseen.** `specialMeterCost: 100` equals `maxMeter: 100` (Story 10.2, deliberately: the whole bar is what makes arming mean something), and only the random bot ever picks `special` at all — `createAggressiveBot` and `createSpacingBot` choose from a fixed v1 vocabulary and never reach for it. So Epic 10's Super Gauge, Story 10.4's cinematic, Story 11.4's three-act version and Story 11.5's voice-and-duck all hang off **one submission in the entire shipped corpus**, at tick 870 of `spectate-03`, on a surface whose sound was off by default until Story 12.9. Four stories of work, visible essentially never.

**Two — every log is `schemaVersion 1.0.0`.** `apps/web/scripts/build-spectate-manifest.mts` calls `buildCommandLog` from `packages/core/src/command-log.ts`, which stamps `SCHEMA_VERSION`. `apps/web/src/arcade/log.ts` already builds a v2 log (`buildArcadeCommandLog`, `SCHEMA_VERSION_V2`), so the writer exists — for the arcade, and nowhere else.

**Three — and this one is not a corpus problem at all.** Epic 8's Actions cannot be chosen:

```ts
// packages/env-fighter/src/frames.ts:215
export function legalActionsFor(config: FighterConfig, meter: number): readonly Action[] {
  if (meter >= config.specialMeterCost) return ACTIONS;
  return ACTIONS.filter((action) => action !== 'special');
}
```

`ACTIONS` is `docs/contracts/index.ts`'s **v1** five. `jump` is in `ACTIONS_V2` and in the frozen contract, and `environment.ts` implements it fully — the rise, the apex, the fall, the gravity divide. But no Agent is ever *offered* it, so no Agent can ever submit it, so no log can ever contain it. Zoned strikes are the same shape: `step()` takes an optional `zones` argument, and `EnvironmentAdapter.step()` in the frozen contract is `(state, actions)` with no third parameter, so no Harness caller can supply one. Juggles follow, since they need multi-hit strings the above cannot produce.

And even if a log did contain a jump: **`verticalPosition` is read by nothing in `apps/web/src`.** There is no renderer path that draws a fighter off the ground.

## What this story does, and what it must refuse to do

**It regenerates the corpus. It does not change the simulation.**

Findings one and two are corpus problems and this story fixes both:

- **Emit v2.** The manifest builder writes `CommandLogV2` at `SCHEMA_VERSION_V2`, the way `arcade/log.ts` already does. If that means promoting a shared v2 builder into `packages/core/`, that is a code move, not a contract change — `command-log.v2.schema.json` is frozen and the output validates against it unchanged.
- **Search seeds rather than change balance.** The random bot picks `special` whenever the meter is full and the die lands on it, so a search over seeds and bot pairings finds Matches that contain several Ultimates and end in KOs. This is selection, not tuning: `DEFAULT_FIGHTER_CONFIG` is not touched, so `configHash` is unchanged and no existing gate is re-opened. The search runs in the committed generator script and its selection criteria are written down there, so the corpus is reproducible rather than a set of lucky files.
- **Fix the frame counts the same way Story 11.6 had to.** A juice track is the film's length plus every hitstop hold plus every cinematic freeze, and `manifest.json`'s `frameCount` must be the **track's** length or `offsetForNow` drops a visitor at the wrong place. More Ultimates means more freeze, which means this drifts further than it did before. Regeneration is by the committed script, never by hand.

Finding three is a **simulation gap and this story does not fix it.** Making `jump` legal changes what every bot can choose, changes the action distribution, changes Final-State Hashes for anything regenerated, and re-opens the Story 8.5 skill-separation re-gate. Epic 12 is a presentation epic that re-runs no gate. A dev session that quietly widens `legalActionsFor` to make a screenshot better has done the single most damaging thing available to it in this repository.

So the third finding is **escalated**, not waived. A waiver names a later story that owes the fix; no story in this epic owns this one, and inventing an owner would be the waiver file becoming a list of checks nobody runs — which is the exact failure `docs/visual/known-failures.json` documents itself against. This story writes the finding up, files it as deferred work with its measurements, and leaves the decision with the owner.

## Acceptance criteria

**Given** the regenerated corpus, **When** each file under `apps/web/public/replays/` is read, **Then** every one is `schemaVersion` v2 and validates against `docs/contracts/command-log.v2.schema.json` unchanged — asserted by `scripts/audit-invariants.sh`, because this is a file fact and the visual gate cannot see it.

**Given** the regenerated corpus, **When** its endings are counted, **Then** at least half end in `ko` rather than `timeout`, and **every** entry contains at least one `special`. Asserted in the same sweep, over the directory rather than over a list of filenames.

**Given** a visitor on the watch screen, **When** the entry the manifest marks as containing an Ultimate plays, **Then** the cinematic draws — the check `spectate-shows-an-ultimate`, added to `scripts/visual-gate.mjs` by this story, which selects that entry from the picker and requires the letterbox plate and the caster's name to appear within its run. The caster's name is the load-bearing detail: it can only be drawn when the Ultimate sheet **and** the roster both reached the paint, which Story 11.6 established as the difference between the first-level degrade and the third.

**Given** the regenerated corpus, **When** the manifest is rebuilt, **Then** each entry's `frameCount` is the track's length and `offsetForNow` lands a visitor at the same **proportion** through a Match as before. Regeneration by the committed script only.

**Given** the whole corpus, **When** each log is verified, **Then** each reproduces its own Final-State Hash. New logs, honestly generated, each verifying — that is the entire point of the artefact.

**Given** the replay player and the landing page, **When** they load, **Then** they still work against the new `demo.command-log.json`. The v1→v2 reader path is already exercised by Arcade (`arcade/log.ts`'s docblock records that `film.ts` handles a v2 log with no arcade-specific branch), so this should hold — and if it does not, that is a finding, not a reason to leave the corpus on v1.

**Given** the `jump`, zone and juggle gap, **When** this story completes, **Then** it is recorded in this file with its measurements and filed as deferred work naming `legalActionsFor`, `EnvironmentAdapter.step()`'s frozen arity, and the absence of any `verticalPosition` reader in `apps/web/src` — and **no** waiver is added for it, because no story in this epic owns it. This AC is satisfied by the write-up, not by a fix.

**Given** `docs/contracts/`, **When** this story completes, **Then** it is untouched.

## Scope

`apps/web/scripts/build-spectate-manifest.mts` (v2 emission, the seed search and its recorded criteria), `apps/web/public/replays/*.command-log.json` and `manifest.json` (regenerated output), `packages/core/src/command-log-v2.ts` **only** if a shared v2 builder is promoted there — a move of existing behaviour, adding nothing to the schema, `apps/web/src/spectate/manifest.ts` if an entry needs to record that it contains an Ultimate, `scripts/audit-invariants.sh` (the corpus sweep), `scripts/visual-gate.mjs` (`spectate-shows-an-ultimate`), `docs/ASSETS.md` if the manifest's row changes.

**Explicitly not in scope, and a stop-and-escalate if it looks necessary:** `packages/env-fighter/src/frames.ts`, `packages/env-fighter/src/config.ts`, `packages/env-fighter/src/bots.ts`, and anything under `docs/contracts/`.

## Frozen contracts touched

None. `command-log.v2.schema.json` is frozen and the new logs validate against it as it stands. `ACTIONS`, `ACTIONS_V2` and `EnvironmentAdapter` are frozen and are not widened.

## Invariants at risk

- **INV-2** — every regenerated log must replay to its own hash.
- **INV-3** — `loopStartEpochMs` stays a fixed anchor constant, not a timestamp taken at generation time. Story 11.6 flagged this and it is easy to break while regenerating.
- **AD-17** — the stream stays a walk over committed logs. A seed search is a build-time activity and must not become something a visitor triggers.
- **INV-8** — generation is local and free; no provider, no network.

## Two regimes

No drawing code changes here, so neither regime is engaged — but the story's *output* is what every other Epic 12 story is judged against, so it inherits all of their captures.

## Test plan

- Every file in `apps/web/public/replays/` validates against the v2 schema and verifies its hash, swept over the directory.
- The corpus's KO ratio and per-entry `special` count are asserted, not eyeballed.
- The generator is deterministic: run twice, byte-identical output.
- `offsetForNow` lands at the same proportion before and after.
- The player, the landing carousel and Spectate all mount the new `demo` log.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero, including the new corpus sweep **AND** `node scripts/visual-gate.mjs` exiting zero with `spectate-shows-an-ultimate` passing. The deferred-work entry for the v2-action gap exists and is linked from the Visual check finding.
