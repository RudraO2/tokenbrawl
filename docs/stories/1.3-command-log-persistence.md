# Story 1.3 — Command Log persistence and schema validation

As the developer, I want every Match written as a schema-conformant Command Log, so that every downstream consumer binds to one format instead of inventing its own.

## Acceptance criteria

**Given** a completed Match, **When** the log is written, **Then** it validates against `docs/contracts/command-log.schema.json` with no additional properties.

**Given** a log whose `schemaVersion` is not exactly `1.0.0`, **When** any consumer loads it, **Then** it throws and refuses the document — never a partial read.

**Given** the same environment, seed, configHash and agent ids, **When** `matchId` is derived twice, **Then** it is identical both times.

**Given** a config change that can alter simulation outcome, **When** `configHash` is recomputed, **Then** it differs from the previous value.

**Given** a Parse Failure entry, **When** the log is validated, **Then** `rawResponse` is required and `action` is `stand`.

## Scope

Command Log writer and reader in `packages/core`. One function each for `matchId`, `configHash` and `finalStateHash` — SHA-256 over canonical serialisation with sorted keys, integers only. A test asserting the TypeScript types and the JSON Schema agree.

## Frozen contracts touched

`docs/contracts/command-log.schema.json` and `index.ts` — bound to, not modified.

## Invariants at risk

- **INV-2** — canonical serialisation must be stable; a key-order change silently alters every hash.
- **INV-6** — provider and endpoint fields must be carried through, not dropped on write.

## Architecture decisions that constrain this

- **AD-2** — this is the only cross-boundary format.
- **AD-3** — exact-match version, hard fail.
- **AD-8** — identity and hashes derived by one function in core, so runner and player cannot disagree.

## Test plan

Schema validation round-trip. Unknown-version rejection. Hash stability across key insertion orders. Types-versus-schema agreement test.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Never widen a frozen interface.
