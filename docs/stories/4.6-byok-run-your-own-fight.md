# Story 4.6 — Run your own fight, in the browser

As a curious visitor with free API keys, I want to run my own matchup without installing anything, so that I can try the thing rather than only watch it.

## Acceptance criteria

**Given** a visitor pastes two API keys, **When** a Match runs, **Then** the keys are transmitted **only** to the model provider that visitor selected, and to no other origin.

**Given** the keys, **When** the Match runs, **Then** they are never persisted to any server, never written to the repository, and never passed into `packages/core`.

**Given** an invalid or rate-limited key, **When** the Match is attempted, **Then** the visitor is told **which** key failed and why, and no partially-recorded Match is produced.

**Given** a completed BYOK Match, **When** it is played back, **Then** it is a valid Command Log with `provider: "byok"` and it is **excluded from all rating computation**.

**Given** a provider that does not permit direct browser calls, **When** the picker is shown, **Then** that provider is listed as CLI-only rather than failing at request time.

## Scope

`apps/web`: the BYOK panel, browser-side match execution, and key handling. Verify CORS support per provider before offering it in the picker.

Storing a key in `localStorage` requires an explicit opt-in from the visitor. Default is not to persist.

## Frozen contracts touched

`command-log.schema.json` — `provider: "byok"` already exists in the enum. Use it.

## Invariants at risk

- **INV-8** — no server may be introduced to proxy these calls. If a provider cannot be reached from the browser, it is CLI-only.
- **INV-6** — provenance still recorded per call.

## Architecture decisions that constrain this

- **AD-11** — BYOK Matches never enter the leaderboard.
- **AD-4** — the same engine that ran in CI runs in the tab.

## Test plan

A test asserting no request carrying a key targets any origin other than the selected provider. Key-never-reaches-core assertion. Attributed error for each failure mode. BYOK exclusion from rating computation. CLI-only labelling for non-CORS providers.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**.
