# Story 4.1 — Canvas renderer replaying a Command Log

As a visitor, I want to watch a fight play out smoothly, so that I can see what happened without knowing anything about how it was produced.

## Acceptance criteria

**Given** a Command Log, **When** the player loads it, **Then** it reproduces visual state by re-running the engine from seed, config and ordered actions — it does **not** read stored per-tick positions, because none exist.

**Given** a Match between two slow Deployments and one between two fast ones, **When** both are played, **Then** frame pacing is identical.

**Given** the player source, **When** inspected, **Then** it reads no wall-clock or latency field, and the schema exposes none.

**Given** playback, **When** it runs, **Then** it renders at a constant 60 frames per playback second regardless of the original Match.

**Given** a replayed Match, **When** it ends, **Then** the reproduced final state matches the log's `finalStateHash`.

## Scope

`apps/web`: canvas renderer plus CC0 sprite integration. Import `packages/env-fighter` and re-simulate. Record the exact source and licence of every sprite asset in the repo as it is added — reconstructing provenance later is how licence problems become real ones.

**Use CC0 assets only** (Martial Hero family or similar). FightingICE / Rumble Fish 2 sprites are rejected: Dimps grants use for research purposes, and no redistribution licence exists.

## Frozen contracts touched

`docs/contracts/command-log.schema.json` — read only.

## Invariants at risk

- **INV-3** — playback must carry no timing signal whatsoever.
- **INV-2** — every replay is a live determinism check; a hash mismatch here is a real bug, not a rendering glitch.

## Architecture decisions that constrain this

- **AD-4** — replay is re-simulation. This is the only consumer-to-adapter dependency the architecture permits.
- **AD-3** — reject an unknown `schemaVersion` outright.

## Test plan

Frame-pacing equality across fast and slow Matches. Hash verification after replay. A test asserting no latency field is read. Visual check via the Chrome DevTools MCP — do not ship a layout you have not looked at.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.
