# Story 9.6 — Three-bus audio layer

As a visitor, I want music, hits, and voice lines mixed properly instead of one flat channel, so that the fight sounds like it was designed rather than bolted on.

Read `Desktop/Extraction/game_local/js/audio.js` (via Story 9.1's dev-reference) for behavioral facts — which events trigger which sound category, how buses duck against each other — not for code to transliterate. Same standing rule as Story 9.5.

## Acceptance criteria

**Given** music, sound effects, and voice lines, **When** any plays, **Then** each mixes through its own independent WebAudio gain bus.

**Given** a missing audio asset, **When** playback is attempted, **Then** it fails soft — the Match keeps playing silently, never throws. Mirrors the fail-soft sprite pattern `docs/ASSETS.md` already documents.

**Given** any audio trigger, **When** timed, **Then** it is driven by the same frame-counted Command Log event stream as Story 9.5's juice layer — never a wall-clock timer.

**Given** audio playback, **When** a viewer listens to a Match, **Then** nothing in the mix reveals how long any Agent took to think — INV-3's "no timing signal" guarantee extends to the audio channel, not only the visual one.

## Scope

`apps/web/src`: a new audio module with three `GainNode`s (music/SFX/voice), asset loading via the existing fail-soft pattern.

## Frozen contracts touched

None.

## Invariants at risk

- **INV-1** — no wall-clock trigger path.
- **INV-3** — audio must not leak Agent latency any more than the visual player does.

## Architecture decisions that constrain this

- **AD-15** — audio is presentation code, lives in `apps/web` only, hash-neutral.

## Test plan

Fail-soft test: a missing audio file does not throw and playback continues. Audit-sweep test for wall-clock APIs in the audio module. Trigger-timing test: audio cues fire on frame index, not elapsed real time, verified with a fake clock the same way Story 9.5's is.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero.

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Same translate-vs-reimplement boundary as Story 9.5 applies here.
