# Story 1.2 — Agent port, mock environment, and the blocking match runner

As the developer, I want a match runner that blocks on agents indefinitely, so that a slow model and a fast model have identical in-game effect.

## Acceptance criteria

**Given** a mock Agent that sleeps 40 seconds and one that returns instantly, **When** both play the same seed with the same scripted action sequence, **Then** the resulting Command Logs are byte-identical.

**Given** an Agent that never returns, **When** the match runs, **Then** no default Action is ever substituted — the runner waits. Test with a cancellable promise, not a real hang.

**Given** a mock EnvironmentAdapter, **When** the runner steps it, **Then** both Actions for one Decision Point are applied simultaneously and neither Agent can observe the other's choice for that tick.

**Given** an Agent inside a Commitment Window, **When** the Decision Point arrives, **Then** that Agent is not polled at all.

## Scope

Implement the `Agent` and `EnvironmentAdapter` ports from `docs/contracts/index.ts` in `packages/core`. Build a trivial deterministic mock environment — not the fighter — and two scripted mock agents. Match runner loop only: no Token Bank yet, no Command Log persistence yet.

## Frozen contracts touched

`docs/contracts/index.ts` — implemented, not modified.

## Invariants at risk

- **INV-1** — the entire point of this story. No `Date.now`, no timers, no timeout-driven defaults anywhere in the loop.
- **INV-3** — core imports no DOM or canvas API.

## Architecture decisions that constrain this

- **AD-1** — one-way dependency; core stays pure.
- **AD-7** — Scaffold and prompt assembly live in core, never in an adapter.

## Test plan

The 40-second-versus-instant equivalence test is the headline. Plus simultaneity, non-polling inside Commitment Windows, and a test asserting no timer API is reachable from the runner.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Never widen a frozen interface.
