# Story 9.5 — Frame-counted juice layer

As a visitor, I want a hit to feel like a hit — freeze, shake, spark, a number — so that this reads as a real fighting game and not a state-machine demo.

**Highest-risk story in this epic for the translate-vs-reimplement line.** Read `Desktop/Extraction/game_local/js/vfx.js` (via Story 9.1's dev-reference) for *behavioral facts only* — how many frames a hitstop holds, how shake amplitude decays, what triggers a spark. Match those numbers exactly if desired; they are not protectable expression. Do not open `vfx.js` and this story's new file side by side and transliterate — write fresh code against Tokenbrawl's own event-stream architecture. See the PRD addendum's "What 'identical look and feel' actually means, mechanically" section before starting.

## Acceptance criteria

**Given** a hit connects, **When** the event appears in the Command Log's event stream, **Then** rendering freezes (hitstop) for a configured frame count.

**Given** damage dealt, **When** a hit lands, **Then** screen-shake amplitude scales with the damage value, via a data-driven curve, not a hardcoded multiplier.

**Given** a hit or a KO, **When** it occurs, **Then** hit sparks and a floating damage number render at the event's position.

**Given** any juice effect, **When** timed, **Then** its duration derives from a Tick or film-frame count — never a wall-clock timer. A test extends the existing INV-1/INV-3 audit sweep to cover this new module for `Date.now`/`setTimeout`/`performance.now`.

**Given** any juice effect, **When** added, removed, or retuned, **Then** a Match's Final-State Hash and replay determinism are provably unaffected — strip the effect, re-hash, compare.

## Scope

`apps/web/src/render` only: a new effects module consuming the Command Log's event stream. No `packages/*` change.

## Frozen contracts touched

None.

## Invariants at risk

- **INV-1** — no wall-clock path anywhere in this module.
- **INV-2** — juice must not perturb the Final-State Hash.
- **INV-3** — rendering stays decoupled from decision-making; juice is cosmetic by construction.

## Architecture decisions that constrain this

- **AD-15** — this story is a primary implementation of it: presentation code in `apps/web` only, provably hash-neutral.

## Test plan

Audit-sweep test confirming no wall-clock API appears in the new module. Hash-neutrality test: a fixture Match's `finalStateHash` is identical with the effects module present versus stubbed out. Effect-duration test: drive a fake `requestFrame` and confirm an effect completes in exactly its configured frame count regardless of real elapsed time.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero **AND** the hash-neutrality test passing explicitly.
