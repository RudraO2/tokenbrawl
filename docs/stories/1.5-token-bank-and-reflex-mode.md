# Story 1.5 — Token Bank metering and Reflex Mode

As the developer, I want thinking budget metered rather than set, so that scarcity applies symmetrically instead of replacing the latency confound with a units confound.

## Acceptance criteria

**Given** any serialised request body produced by the system, **When** inspected, **Then** it contains no `reasoning`, `reasoning_effort`, `thinking`, or `thinkingLevel` key.

**Given** a call reporting N completion tokens, **When** it completes, **Then** `bankRemaining` equals the previous value minus N, and both are recorded on the Decision Point entry.

**Given** a provider reporting no usage at all, **When** the call completes, **Then** `tokensSpent` is `null` — never coerced to zero.

**Given** a Token Bank that reaches zero, **When** the next call is made, **Then** it uses `max_tokens=8` and a bare-Action scaffold, and no later call in that Match exceeds it.

**Given** both Agents exhausting their banks, **When** the Match continues, **Then** it runs to termination with both in Reflex Mode — a valid state, not an error.

## Scope

Token Bank accounting in `packages/core`. Starting size is a **config value**, provisionally 25,000 completion tokens per Agent per Match. Never hard-code it.

## Frozen contracts touched

`docs/contracts/index.ts` — `Decision.tokensSpent` is nullable by design. Do not change that.

## Invariants at risk

- **INV-4** — metered, never set. The audit script greps for effort parameters.

## Architecture decisions that constrain this

- **AD-6** — the Harness owns the debit and the Reflex Mode transition. A provider adapter reports raw usage and nothing else.

## Test plan

Assert against captured request payloads that no effort parameter is sent. Debit arithmetic. Null-versus-zero distinction. Exhaustion transition at exactly the right Decision Point. Both-exhausted case.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Never widen a frozen interface.
