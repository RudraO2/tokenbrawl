# Story 2.1 — Fighter state model and deterministic step function

As the developer, I want a fighting-game simulation that is integer-only and rendering-free, so that replays are bit-identical and the engine can run in CI and in a browser tab alike.

## Acceptance criteria

**Given** identical seed, config and ordered Actions, **When** the environment is stepped twice, **Then** both runs produce identical Final-State Hashes.

**Given** the simulation source, **When** inspected, **Then** it contains no floating-point values in state — positions, health, meter, and timers are all integers.

**Given** a match running in CI, **When** it completes, **Then** no rendering or canvas API was touched, and the module imports none.

**Given** the process is artificially stalled mid-Match, **When** it resumes, **Then** output is unchanged.

**Given** the PRNG, **When** it is used, **Then** it lives inside the state object and is threaded forward explicitly — no module-level generator anywhere.

## Scope

`packages/env-fighter`: state shape, fixed-timestep step function, seeded PRNG, and the `hash` implementation. Two fighters on one horizontal axis, health pools, positions in integer units. Implements the `EnvironmentAdapter` port.

Frame data — exact startup/active/recovery values, damage, meter costs, range bands — is deliberately not fixed by the architecture. Choose starting values here; story 2.4 calibrates them.

## Frozen contracts touched

`docs/contracts/index.ts` `EnvironmentAdapter` — implemented, not modified. Nothing fighting-game-specific may leak upward into the port.

## Invariants at risk

- **INV-2** — the whole story. Floats, module-global PRNG, or unordered iteration all break it.
- **INV-3** — no rendering during simulation.
- **INV-1** — no wall-clock reads. 60 ticks/second is a playback rate the simulation must never read.

## Architecture decisions that constrain this

- **AD-5** — determinism is structural, not tested-in.
- **AD-4** — must run unchanged in Node and browser. No Node builtins.
- **AD-1** — the adapter depends on core, never the reverse.

## Test plan

Same-seed reproducibility. Cross-process reproducibility. A grep-level test that state contains no floats. Stall-resistance test. A test proving the PRNG is not shared between two concurrent match instances.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Never widen a frozen interface.
