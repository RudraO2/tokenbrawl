# Story 10.4 — The Ultimate is a cinematic, not a frame

As a visitor, I want the Ultimate to stop the fight and command attention, so that it lands like an arcade super rather than a fast poke.

## The decision that shapes this story

The reference freezes **both fighters for 90 ticks inside its simulation** (`CINEMATIC_FREEZE = 90` in its `core.js`). Porting that literally would change Tick counts, Match length, the Decision Point budget, and every Final-State Hash in this repository — turning a presentation flourish into a balance change and invalidating every committed Command Log.

**So the freeze is held by the renderer, over playback frames, and the simulation is untouched.** AD-15 already requires the juice layer to be hash-neutral, and Story 9.5's frame-counted juice layer already exists to hang this on. A Match hashes identically with the cinematic present or removed, and that is asserted rather than assumed.

## Acceptance criteria

**Given** an Ultimate entering its active phase, **When** playback reaches it, **Then** the renderer holds a freeze for a fixed number of **playback frames**, during which the fight does not advance on screen.

**Given** that freeze, **When** the simulation is examined, **Then** it is completely unaffected: Tick count, Match length, Decision Point budget and Final-State Hash are byte-identical whether the cinematic layer is enabled or disabled. A test proves this by hashing the same Match both ways and asserting equality.

**Given** the freeze, **When** its duration is expressed, **Then** it is counted in frames, never in milliseconds and never from a clock (INV-1, INV-3).

**Given** the timeline scrubber from Story 4.5, **When** a visitor seeks across an Ultimate, **Then** playback remains seek-safe: the cinematic is a pure function of the frame index, so scrubbing backwards and forwards over it produces identical output rather than a stuck or double-triggered effect.

**Given** the Ultimate connecting, **When** it is drawn, **Then** it carries a flash, a screen shake and an impact mark through the **existing** frame-counted juice layer — extended, never reimplemented alongside it.

**Given** the four roster packs, **When** the Ultimate plays, **Then** it uses the existing `special-startup` / `special-active` / `special-recovery` clips. All four packs already ship distinct art for these three phases — verified by content hash, they are not copies of the attack clips — so no new art is required by this story.

**Given** a Baseline Bot Match with no Ultimate thrown, **When** it plays back, **Then** nothing about it changes.

## Scope

`apps/web/src/render/juice.ts`, `apps/web/src/render/juice-draw.ts`, `apps/web/src/render/renderer.ts`, and the playback clock in `apps/web/src/player/`. **No `packages/env-fighter` change whatsoever** — if this story appears to need one, stop and escalate.

## Frozen contracts touched

None.

## Invariants at risk

- **AD-15** — the whole story is a hash-neutrality claim. This is its central risk.
- **INV-1 / INV-3** — frames, never time.

## Standing rule — translate, do not reimplement

This story carries the same risk Story 9.5 flagged and it is repeated here because it is the likeliest way this story goes wrong. The reference's VFX are written against a 60fps real-time loop with its own particle pool and its own RNG. **Do not port that pool.** Express the same *look* in this project's frame-counted, deterministic, hash-neutral juice layer. A particle system that reads a clock or draws from an ungoverned RNG breaks INV-1 and AD-15 at once, and would do so while still producing a plausible-looking screenshot.

## Test plan

- Final-State Hash identical with the cinematic layer enabled and disabled — the core assertion.
- The cinematic's drawn output is a pure function of frame index: the same index drawn twice yields the same call sequence.
- Seeking backwards across the Ultimate and forwards again reproduces identical frames.
- A Match with no Ultimate produces an unchanged call sequence.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero **AND** the hash-neutrality test passing **AND** Story 10.1's visual gate, with the Ultimate captured **mid-freeze** and compared against the reference project's `shots/`, finding recorded here.
