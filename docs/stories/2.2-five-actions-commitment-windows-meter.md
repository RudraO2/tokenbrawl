# Story 2.2 — Five actions, commitment windows, whiff punishing and the super meter

As a model playing the game, I want actions that commit me for a real span of ticks, so that spacing and timing decide fights rather than reaction speed.

## Acceptance criteria

**Given** an Agent choosing `attack`, **When** the Action resolves, **Then** it occupies a Commitment Window of startup, active, then recovery ticks, during which the Agent is not polled.

**Given** an `attack` whose active phase connects with nothing, **When** it enters recovery, **Then** the attacker is damageable for the full recovery duration.

**Given** an Agent with Super Meter below the `special` cost, **When** it submits `special`, **Then** the Action is rejected as illegal and the Fallback Action applies.

**Given** landed hits, **When** damage resolves, **Then** Super Meter accrues by the configured amount.

**Given** two Agents acting at the same Decision Point, **When** the step resolves, **Then** neither Action influenced the other for that tick.

**Given** a Match, **When** it runs, **Then** Decision Points occur every 30 ticks for actionable Agents only, the Match is capped at 1,200 ticks, and it ends early on KO.

## Scope

`packages/env-fighter`: the five Actions, Commitment Window state machine, hit detection by range band, damage, Super Meter, KO and timeout termination. Config-driven frame data — no magic numbers in code.

## Frozen contracts touched

None modified. `LoggedAction` already includes `stand`; note an Agent may never choose it.

## Invariants at risk

- **INV-2** — hit resolution order must be deterministic and side-independent, or mirrored seeds will disagree.
- **INV-1** — polling cadence must derive from ticks, never elapsed time.

## Architecture decisions that constrain this

- **AD-5** — integer-only resolution; no float damage scaling.
- **AD-7** — the Action grammar shown to models lives in core, not here. This story owns mechanics only.

## Test plan

Commitment Window non-polling. Whiff-then-punish scenario. Illegal `special` rejection. Meter accrual. Simultaneity under both orderings. Tick cap and KO early exit. A mirrored-seed test asserting no side advantage beyond what is intended.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Never widen a frozen interface.
