# Story 1.1 — Scaffold the monorepo and wire the CI gate

As the developer, I want a working monorepo whose CI fails on an invariant violation, so that every story after this one has a real gate rather than an opinion.

## Acceptance criteria

**Given** a fresh clone, **When** `npm install && npm test` runs, **Then** it succeeds with zero packages implemented and at least one passing placeholder test per workspace.

**Given** a push to any branch, **When** GitHub Actions runs, **Then** it executes `npm test` and `bash scripts/audit-invariants.sh` and fails the check if either fails.

**Given** a deliberately planted `Math.random()` in `packages/core`, **When** CI runs, **Then** the check fails with the INV-2 message. Verify once manually, then remove.

**Given** the repo on a Linux runner, **When** the audit script executes, **Then** it does not fail with a bad-interpreter error — `.gitattributes` already forces LF for shell scripts.

## Scope

npm workspaces; TypeScript 5.x strict; Vitest 4; Node 22 LTS; Vite 8 for `apps/web` only. Create the package layout from the architecture spine: `packages/core`, `packages/env-fighter`, `packages/providers`, `packages/cli`, `apps/web`, `replays/`. Each package gets a package.json, a tsconfig extending a strict root config, and one placeholder test.

**No starter template.** Every mainstream TypeScript starter pulls in server-side scaffolding, which contradicts INV-8. Hand-roll it.

## Frozen contracts touched

None modified. `docs/contracts/index.ts` must be importable from every package — wire path mapping or a workspace package so it resolves.

## Invariants at risk

- **INV-8** — do not add a server framework, database driver, or realtime dependency. The audit script checks for these by name.

## Architecture decisions that constrain this

- **AD-1** — `packages/core` imports nothing from adapters or apps. Enforce with lint config now, while it is cheap.
- **AD-4** — `env-fighter` must run in Node and browser; no Node builtins in it.

## Test plan

Placeholder test per workspace proving the runner works. A test asserting the contracts file type-checks under strict mode. Manual one-off: plant a violation, confirm CI red, remove.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero. Reviewer opinion is never a gate.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Never widen a frozen interface — every parallel agent is building against it.
