# Story 8.5 — The v2 skill-separation re-gate

As the developer, I want proof that the extended jump/Zone/juggle Action space still separates a stronger player from a weaker one, so that a v2 leaderboard measures something instead of producing noise.

**Mirrors Story 2.4's role exactly, for the extended engine. Does not block Epic 9** — Arcade and Spectate carry no ranking claim (AD-14 excludes any `"human"`-containing Match from rating, and Spectate only replays what already exists), so nothing in Epic 9 waits on this gate. It blocks **v2 Deployment ranking only** (feeding Epic 7).

## Acceptance criteria

**Given** the graded Baseline Bot ladder, **When** each pairing plays on the extended Action space (jump, Zone, juggle available to all bots), **Then** win rates are strictly ordered with non-overlapping 95% confidence intervals — same method as Story 2.4, same ≥200-Matches-per-pairing floor.

**Given** those results, **When** CI lower bounds are computed, **Then** thresholds equivalent to FR-3's (0.65 / 0.55 / 0.50, or a revised set argued and committed *before* seeing results — never after) hold.

**Given** the gate run, **When** it completes, **Then** a committed report records win rates, CIs, match counts, and the v2 frame-data config hash used — alongside the existing v1 report, not overwriting it.

**Given** the existing three-bot ladder, **When** it is run against the extended space, **Then** either it separates cleanly, or the finding is recorded plainly: the bots may need a fourth member that specifically exploits jump or Zone mixups (`OQ-8`). Adding a bot is deepening the game, the same move Story 2.4 sanctions — it is not a threshold problem.

**Given** a failing gate, **When** the run finishes, **Then** the story **stops and escalates**. No v2 Deployment ranking is published until this passes.

## Scope

Re-run (or extend) the Story 2.4 gate runner against the v2 engine. No LLMs involved — Baseline Bots only, exactly as before.

## Frozen contracts touched

None modified. Gate matches produce ordinary v2 Command Logs per Story 8.1's schema.

## Invariants at risk

- **INV-2** — 200+ matches per pairing on new code will surface any non-determinism Stories 8.2-8.4 missed. A hash mismatch here is a determinism bug, not flakiness.

## Architecture decisions that constrain this

- **AD-12** — every seed played from both sides, side swaps as separate Matches.
- **AD-5** — bootstrap resampling is itself seeded.
- **AD-13** — the report this story produces is versioned alongside the v1 report it does not replace.

## Test plan

The gate run is the test. If the existing bootstrap-CI unit tests from Story 2.4 already cover the statistical machinery, this story does not re-test that machinery — it re-runs it against new data and asserts the thresholds.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero **AND** the committed CI thresholds met on the v2 engine.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`, **stop and escalate**. Never widen a frozen interface. Equally: never widen the gate thresholds to fit a disappointing result — that failure mode was already ruled out once for v1, and applies here with the same force.
