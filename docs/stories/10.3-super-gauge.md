# Story 10.3 — The Super Gauge reads as a weapon being charged

As a visitor, I want the bar under the health bar to visibly charge and then arm, so that I can see an Ultimate coming before it lands.

## Why this story exists

The meter is already drawn — `renderer.ts` paints it as a 10px bar under the health bar, filled in `theme.ink`. It is a hairline, it looks like a rule rather than a resource, and at full it looks exactly as it does at 99%. A visitor has no way to know an Ultimate is available, which is the entire tension the Action is supposed to create.

## Acceptance criteria

**Given** the meter bar in `renderer.ts`, **When** meter is below full, **Then** it fills proportionally and is legibly a *gauge* — sized so a viewer reads it as a resource being accumulated, not as a divider.

**Given** meter at full, **When** the bar is drawn, **Then** it enters an armed state that is unmistakable at a glance: the bar reads `ULTIMATE READY` in ground ink over a filled bar, in the same warn-as-fill language `drawTokenBank` already uses for `REFLEX`. Reusing that pattern is deliberate — the page already teaches a viewer that an inverted, filled bar carrying a word means *a threshold has been crossed*.

**Given** the armed state, **When** it is animated at all, **Then** any pulse is driven by the frame counter the juice layer already uses (`frame.index`), never by a clock or a `Date` (INV-1, INV-3). A replay seeked to the same frame twice must draw the identical gauge.

**Given** `docs/DESIGN.md`, **When** the gauge is styled, **Then** it obeys the house style — flat fills, square corners, hard offset shadow, no gradient, no glow, no translucency. `fillRect` cannot produce a rounded corner, so most of this holds by construction; the rule still gets checked rather than assumed.

**Given** a Baseline Bot with no Token Bank, **When** the gauge is drawn, **Then** the existing bank/meter distinction is preserved — this story changes the Super Meter's presentation only, and must not disturb Story 4.4's Token Bank row beneath it.

**Given** all three rendering surfaces, **When** the gauge is checked, **Then** the replay player, Arcade and Spectate each show it (Story 10.1).

**Given** any Match, **When** its Final-State Hash is compared before and after this story, **Then** it is unchanged. This story is presentation only.
