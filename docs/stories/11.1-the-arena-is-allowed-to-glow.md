# Story 11.1 — The arena is allowed to glow

As the owner, I want the flat-surface rules to govern the page and not the
fight, so that the arena can look like an arcade game while the site around it
stays the instrument panel it is.

## The ruling this story implements

`docs/DESIGN.md` bans translucency, gradients and blur outright, and
`style-discipline.test.ts` enforces that ban across **both** the stylesheets and
`apps/web/src/render/*.ts`. The canvas half of that was never a deliberate
decision — Story 4.1 wrote `globalAlpha = 0.55` across a whole sprite frame,
which painted a red pane over a third of the arena, and the sweep that caught it
was written to stop *that*.

**The owner's ruling, 2026-08-07: those rules were meant for the UI, not for the
game.** Quote: *"All the rules that we have made for design.md and other things
were for the UI not for the game itself inside Token Brawl."*

So the ban is **narrowed, not removed**. Page chrome — panels, buttons, the
leaderboard, every stylesheet — keeps every rule it has today. The arena canvas
is released, because a fighting game's impact reads through light, and light is
alpha.

## Acceptance criteria

**Given** the stylesheets, **When** the discipline sweep runs, **Then** every
rule it enforces today still holds: no `rgba(`, no gradient, no `backdrop-filter`,
no blurred or inset shadow, no rounded corner, no removed focus ring.

**Given** the arena's drawing code, **When** it composites with alpha, a
gradient or an additive blend, **Then** the suite permits it — and the exemption
is expressed as a **named boundary** rather than as a hole. A reader must be
able to see which files are game and which are page without running anything.

**Given** the exemption, **When** a file outside that boundary assigns
`globalAlpha` anything but `1`, **Then** the sweep still fails. The Story 4.1
defect must stay caught for every file the ruling did not release.

**Given** `docs/DESIGN.md`, **When** it is read, **Then** it states the two
regimes and why they differ, in the same change. A rule that lives only in a
test is a rule nobody can look up.

**Given** any Match, **When** its Final-State Hash is compared before and after,
**Then** it is unchanged. This story changes no drawing at all.

## Scope

`apps/web/src/style-discipline.test.ts`, `docs/DESIGN.md`. No rendering change —
this story only moves the fence. The drawing that uses the new freedom is
11.2 onward.

## Frozen contracts touched

None.

## Invariants at risk

- **AD-15** — untouched: presentation stays out of the hash, and nothing here
  draws.
- The offline sweep and the self-hosted-font rules are **not** in scope and must
  keep applying everywhere, page and arena alike (INV-8).

## Test plan

- The stylesheet rules still fail on a planted `rgba(` in a `.css` file.
- A planted `globalAlpha = 0.5` in a page-side `.ts` file still fails.
- The same line inside the arena boundary passes.
- `docs/DESIGN.md` names both regimes.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero **AND**
`docs/DESIGN.md` updated in the same change. No visual gate: nothing renders
differently yet, and saying so is the finding.
