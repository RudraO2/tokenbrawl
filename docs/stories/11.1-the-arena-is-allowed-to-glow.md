# Story 11.1 — The arena is allowed to glow

As the owner, I want the flat-surface rules to govern the page and not the
fight, so that the arena can look like the reference arcade game while the site
around it stays the instrument panel it is.

**Read `docs/DEV-REFERENCE.md` first.** It says where the reference project is,
what may be copied from it, and the four mechanisms that may never be.

## The ruling this story implements

`docs/DESIGN.md` bans translucency, gradients and blur outright, and
`style-discipline.test.ts` enforces that ban across **both** the stylesheets and
`apps/web/src/render/*.ts`. The canvas half was never a deliberate decision —
Story 4.1 wrote `globalAlpha = 0.55` across a whole sprite frame, painting a red
pane over a third of the arena, and the sweep was written to stop *that*.

**The owner's ruling, 2026-08-07:** those rules were meant for the UI, not the
game. Quote: *"All the rules that we have made for design.md and other things
were for the UI not for the game itself inside Token Brawl."* And the goal
restated: *"what we need is a copy of a next-gen arena game inside an LLM eval
with its look and feel and cinematics and everything the same, but modified
minimally so that there are 4 players only and it works with our benchmarking."*

So the ban is **narrowed, not removed**. Page chrome keeps every rule it has.
The arena canvas is released, because a fighting game's impact reads through
light, and light is alpha.

## Four rules clash, not one

An audit on 2026-08-07 found that translucency is only the first of them. All
four must be settled by this story or E11 stalls on whichever one it hits next.

| Rule in `style-discipline.test.ts` | What it blocks | Resolution |
|---|---|---|
| *"uses no translucent or blurred surface"* — bans `rgba(`, `linear-gradient`, `radial-gradient` | Every glow, vignette, aura and health-bar gradient | **Scope to page files.** Arena released. |
| *"sets no partial alpha outside the one place scenery is dimmed"* — bans `globalAlpha != 1` | Every additive and glow layer | **Scope to page files.** `render/backdrop.ts`'s named exemption becomes unnecessary but is kept. |
| *"keeps every hex literal in tokens.css or theme.ts"* | The reference's gold, its three health tiers, and one aura colour per fighter — none of which are Tokenbrawl brand tokens | **Keep the rule, add a second source.** A new arena palette module joins `tokens.css` and `theme.ts` as a permitted colour source, so the arena's colours are still declared in exactly one place rather than scattered as literals. |
| *"declares the two chosen faces and no third family"* | An arcade display face for HUD numerals and callouts | **Keep for CSS. Decide deliberately for the canvas.** If Story 11.3 wants arcade type it must either render it from a glyph table (as `hero/font.ts` already does) or add a third `@font-face` **and** update this rule and `docs/ASSETS.md` in the same change. It may not simply drift in. |

Two rules that look like clashes and are not, confirmed by reading the tests:
*"blurs no shadow"* matches the CSS `box-shadow:` declaration only, so canvas
`shadowBlur` is untouched; *"rounds no corner"* matches the CSS
`border-radius:` declaration only, so a canvas rounded path is untouched. No
change needed for either.

## What this story does **not** touch

`source-discipline.test.ts` stays exactly as it is. Its wall-clock sweep, its
`deltaTime` ban and its module-level-mutable-binding ban are **not** style
rules — they are what makes the benchmark's claims true, and they are precisely
the four mechanisms `docs/DEV-REFERENCE.md` forbids copying. A story that finds
itself wanting to relax `source-discipline.test.ts` has misread this epic and
must stop and escalate.

## Acceptance criteria

**Given** the stylesheets, **When** the discipline sweep runs, **Then** every
rule it enforces today still holds for them: no `rgba(`, no gradient, no
`backdrop-filter`, no blurred or inset shadow, no rounded corner, no removed
focus ring, no third font family, stepped transitions only.

**Given** the arena's drawing code, **When** it composites with alpha, a
gradient or an additive blend, **Then** the suite permits it — and the exemption
is a **named boundary** rather than a hole. A reader must be able to see which
files are game and which are page without running anything.

**Given** a file outside that boundary, **When** it assigns `globalAlpha`
anything but `1`, **Then** the sweep still fails. The Story 4.1 defect stays
caught everywhere the ruling did not release.

**Given** the arena's colours, **When** they are written, **Then** they live in
one declared palette module, and a raw hex literal at a call site inside the
arena still fails the sweep. Releasing the arena from the *brand* palette must
not release it from having a palette.

**Given** `source-discipline.test.ts`, **When** this story is done, **Then** it
is unchanged, and a test asserts the wall-clock sweep still covers every render
file.

**Given** `docs/DESIGN.md`, **When** it is read, **Then** it states the two
regimes, where the boundary runs and why, in the same change. A rule that lives
only in a test is a rule nobody can look up.

**Given** any Match, **When** its Final-State Hash is compared before and after,
**Then** it is unchanged. This story changes no drawing at all.

## Scope

`apps/web/src/style-discipline.test.ts`, a new arena palette module under
`apps/web/src/render/`, `docs/DESIGN.md`. **No rendering change** — this story
only moves the fence. The drawing that uses the new freedom is 11.2 onward.

None.

## Invariants at risk

- **AD-15** — untouched: nothing here draws.
- **INV-8** — the offline sweep and the self-hosted-font rules are **not** in
  scope and keep applying everywhere, page and arena alike.
- **INV-1 / INV-3** — explicitly *not* relaxed. See "What this story does not
  touch".

## Test plan

- A planted `rgba(` in a `.css` file still fails.
- A planted `globalAlpha = 0.5` in a page-side `.ts` file still fails.
- The same line inside the arena boundary passes.
- A planted raw hex inside the arena, outside the palette module, still fails.
- The wall-clock sweep still names every render file.
- `docs/DESIGN.md` names both regimes.

## Exit gate

`npm test` green **AND** `bash scripts/audit-invariants.sh` exiting zero **AND**
`docs/DESIGN.md` updated in the same change. **No visual gate:** nothing renders
differently yet, and recording that as the finding is the honest outcome.

## Standing rule

If this story appears to require a change to anything in `docs/contracts/`,
**stop and escalate**.
